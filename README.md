# 🕵️ Пробив Бот ТГ — быстрый OSINT и поиск по номеру, нику, email и соцсетям

**Пробив Бот ТГ** — это удобный Telegram-бот для мгновенного поиска информации и OSINT-анализа.  
Сервис помогает находить данные по **телефонным номерам, никам, email и аккаунтам в соцсетях**, используя открытые источники и базы утечек. Быстро, надёжно и анонимно.

## 🔎 Основные функции
- 📱 Поиск по номеру телефона — оператор, регион, возможные привязки.  
- 👤 Проверка ника — поиск профилей в Telegram и других сервисах.  
- 📧 Анализ email — поиск связанных аккаунтов и упоминаний.  
- 🌍 OSINT — сбор данных из открытых источников и баз утечек.  
- 🔒 Анонимность — всё работает внутри Telegram, без лишних действий.
