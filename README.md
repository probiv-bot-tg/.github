# .github
Пробив бот ТГ — универсальный Telegram-бот для OSINT и мгновенного пробива: проверка номеров телефонов, никнеймов, email и аккаунтов в соцсетях, сверка с базами утечек и открытыми источниками. Удобный интерфейс, высокая скорость и анонимность делают его отличным инструментом для поиска людей и анализа данных.
